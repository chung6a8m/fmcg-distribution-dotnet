No cross-workflow output/artifact trust, no new allowlist or bypass flag. Classifier success includes immutable business, business/link/E-SIM and native Git/gate tests, plus a source-bound run/attempt artifact. Main always Full. Full fallback runs original workers; invalid/missing classification cannot pass a gate. The exact inventory lives in `tools/verify_doc_ci_companions.py`; APP-00A receipt verification reused unchanged. All public check names are now always-evaluated aggregate gates on the same workflow, each depends on classify and every original worker/light-only substitute. All original worker command blocks, runners, checkout refs, timeouts, conditions internal to steps, cleanup, versions and artifacts retained; only outer job IDs, names, dependencies and route conditions change. Retained security/contract jobs run on both routes. Light-only jobs run only on verified docs-only, and must be skipped on Full. Gate uses exact dependency set and receipt bound to event/base/source/integration; checks actual workflow identity; cancellation, missing/extra worker, malformed receipt, mismatch and unexpected skip cannot PASS.
