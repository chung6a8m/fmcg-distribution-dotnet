## Decision meaning and deliberate trade-offs

1. **CI is an engineering execution environment**, not an approved operator-owned PREPROD host. The CI server-mode Vault uses ephemeral in-memory storage and one-share unseal; TLS CA, tokens and audit are disposed per run. Evidence is valid only for the actual ephemeral containers and scripted faults observed, not private production infrastructure, hardening, backup/PITR or real-world network perimeter.
2. **AI independence is review-process independence**. A fresh context must not inherit the implementer's findings or acceptance assertions as truth. The reviewer uses independently fetched GitHub diff, the frozen B.1 source, CI logs, artifacts, mismatch/mutation tests, and rechecks HEAD. Same-chat self-review or automated passing tests alone is insufficient. No human identity, legal attestation or named Security Approver is inferred.
3. **CI-only merge acceptance is a scoped exception**, not a waiver of the original PREPROD requirements. The baseline `PREPROD_RUNTIME_VERIFIED` exit remains CONDITIONAL/NOT_EARNED. All B.9 30 cases, the five G-B gates, two physical PREPROD tenant DBs, reliable revocation source, real backup/restore measures, and actual EV/P0 remain outside PR #50.
4. APP-02B.3–B.9 retain their original Owner-authorized **PREPROD-only** design/implementation scope; PR #50 merge does **not** satisfy their independent acceptance evidence or grant a CI-only verified exit for those increments. Any later extension of this exception requires a separate explicit Owner decision/versioned addendum.
